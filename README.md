# Ret-holl2 — Bloc-notes vocal Android

Application Android native simple :

- le micro démarre automatiquement après autorisation ;
- la dictée française s’affiche immédiatement ;
- reprise automatique de l’écoute ;
- commandes vocales : **RH titre 1**, **RH titre 2**, **RH paragraphe**, **RH efface**, **RH refait**, **RH nouveau** ;
- copie et partage du texte ;
- aucune bibliothèque externe dans l’application.

## Télécharger l’APK

Ouvrez l’onglet **Actions**, sélectionnez **Construire APK**, puis téléchargez l’artefact **Ret-holl2-debug-apk**.

## Compilation locale

```bash
gradle assembleDebug
```

APK généré : `app/build/outputs/apk/debug/app-debug.apk`.
